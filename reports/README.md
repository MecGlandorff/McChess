# Reports

This directory stores short research notes and smoke-test reports.

Reports here may include early diagnostics that are useful for development but
are not necessarily reportable results. Reportable results should also satisfy
the metadata requirements in `RESULTS.md`, `EXPERIMENTS.md`, and
`docs/EVALUATION_PROTOCOL.md`.

Current ResNet-C references:

- `2026-08-11-supervised-resnet-c-epoch30-test-40000.md`: held-out
  40,000-position prefix evaluation for the bundled model.
- `2026-07-16-stockfish-mcts1000-resnet-c-epoch22-200games.md`: completed
  202-game external benchmark.
- `2026-08-11-stockfish-mcts1000-resnet-c-epoch30-22games.md`: small epoch-30
  development benchmark; not a general strength estimate.

- `2026-06-19-stockfish-mcts200-resnet-b-200games.md`: ResNet-B MCTS-200
  external Stockfish-UCI handicap benchmark.
- `2026-07-16-stockfish-mcts1000-resnet-c-epoch22-200games.md`: ResNet-C
  epoch-22 MCTS-1000 external Stockfish-UCI handicap benchmark.
