# Data Configs

Dataset-building configs belong here.

Current configs:

- `lichess_2013_01_full.yaml`: full January 2013 Lichess standard rated PGN
  archive, split by game with a 98/1/1 train/val/test split.
- `lichess_2026_03_05_2000plus.yaml`: recent 3-month Lichess standard rated
  dataset built from a filtered PGN containing March-May 2026 games where both
  players are rated 2000+.
- `lichess_2026_05_2000plus.yaml`: May 2026 Lichess standard rated dataset
  built from a filtered PGN containing games where both players are rated 2000+.
